# Zoom Adv AI

تطبيق سطح مكتب لإدارة الحملات الإعلانية بالذكاء الاصطناعي — Electron + React + Vite

## المتطلبات

- [Node.js](https://nodejs.org/) LTS (v18 أو أحدث)
- npm

## التثبيت والتشغيل

```bash
cd zoom-adv-ai
npm install
npm start
```

## أوامر أخرى

| الأمر | الوصف |
|-------|-------|
| `npm run dev` | تشغيل الواجهة فقط في المتصفح |
| `npm run electron:build` | بناء ملف التثبيت (.exe) مع اختصار سطح المكتب |
| `npm run make:shortcut` | إنشاء اختصار على سطح المكتب (وضع التطوير) |

## الميزات

- لوحة تحكم للحملات الإعلانية
- إنشاء وإدارة الحملات (Facebook, Google, Instagram, TikTok...)
- مساعد AI للاقتراحات وتحليل الأداء
- تحليلات ورسوم بيانية
- واجهة عربية RTL
- اختصار سطح المكتب تلقائي عند التثبيت
